해당 레포지토리는 3D_Game_Programming_with_Directx_12 연습문제의 솔루션입니다. (정확한 답은 아닙니다.)

개발 환경
- visual studio 2022

환경 세팅
1. 속성 -> 링커 -> 시스템 -> 하위 시스템 '콘솔' 에서 '창'으로 변경
2. 속성 -> C/C++ 추가 포함 디렉터리에 'Common'폴더 경로 추가

예제 실행 방법
- 기본적으로 각 챕터마다 예제 솔루션 파일이 있습니다. 예를 들어 Chap6의 4번 예제를 실행하고 싶다면, Chap6_4안의 cpp파일을 Chap6 폴더의 해당하는 솔루션 파일안에 포함시킨후 실행하시면 됩니다.

--------------------------------------------------------------------------------------------------------------------

This repository contains solutions to the exercises from 3D_Game_Programming_with_DirectX_12. (They are not guaranteed to be the exact/correct answers.)

Development environment

Visual Studio 2022

Environment setup

Properties → Linker → System → Subsystem: change from Console to Windows.

Properties → C/C++ → Additional Include Directories: add the path to the Common folder.

How to run the examples

By default, each chapter has its example solution files. For example, to run example 4 from Chapter 6, include the .cpp file from Chap6_4 into the corresponding solution file in the Chap6 folder, then build/run it.
