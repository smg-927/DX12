개발 환경
- visual studio 2022

환경 세팅
1. 속성 -> 링커 -> 시스템 -> 하위 시스템 '콘솔' 에서 '창'으로 변경
2. 속성 -> C/C++ 추가 포함 디렉터리에 'Common'폴더 경로 추가

예제 실행 방법법
- 기본적으로 각 챕터마다 예제 솔루션 파일이 있습니다. 예를 들어 Chap6의 4번 예제를 실행하고 싶다면, Chap6_4안의 cpp파일을 Chap6 폴더의 해당하는 솔루션 파일안에 포함시킨후 실행하시면 됩니다.
